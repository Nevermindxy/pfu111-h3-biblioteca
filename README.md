## Sistema de Prestamos de Biblioteca 


## ¿De qué trata el proyecto?
Este programa es un prototipo en Python que busca modernizar el sistema antiguo de una biblioteca escolar. Reemplaza los registros manuales en papel por un sistema en consola más ordenado, con validaciones y guardado automático de datos.

## Problema que resuelve
El sistema viejo de la institución tenía varios errores comunes:
* Registros incompletos o datos en blanco.
* Préstamos duplicados (un estudiante sacando el mismo material dos veces).
* Falta de control en los días permitidos.
* Pérdida de información cuando se cerraba el programa.

## Qué hace el código (Funcionalidades)
* *Menú interactivo:* Opciones claras para registrar préstamos, consultar la lista o salir del programa.
* *Validaciones estrictas:* Revisa que los campos no estén vacíos y que el código del estudiante cumpla con el formato correcto.
* *Límite de días:* Solo permite préstamos de 1 a 30 días mediante validación numérica.
* *Control de duplicados:* Evita que se registre el mismo material dos veces para el mismo estudiante.
* *Manejo de errores (try-except):* Si alguien ingresa una letra donde iba un número, el programa no se cae
